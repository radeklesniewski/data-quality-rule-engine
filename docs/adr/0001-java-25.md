# 0001. Java 25 toolchain

- Status: Superseded by [ADR-0012](0012-java-21-toolchain.md)
- Date: 2026-11-11

## Context
The brief requires "plain Java 21 (or later)". The development machine has JDK 25. Java 25 is the current LTS.

## Decision
Target Java 25 through a Gradle toolchain (`languageVersion = 25`), using the foojay resolver so a missing JDK is provisioned automatically.

## Consequences
- We can use records, sealed types, pattern matching, virtual threads, scoped values and stable Java 25 APIs.
- Reviewers need JDK 25, or the toolchain resolver downloads it. The README states this up front.
- If a host on Java 21 had to embed the library, we'd lower the core module to `--release 21`. The API uses nothing past 21 except where noted.
